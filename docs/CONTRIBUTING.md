# Contributing

Fork, branch, pull request.

```sh
# 1. Fork the repo on GitHub, then clone your fork
git clone https://github.com/<you>/quesadilla
cd quesadilla

# 2. Create a branch and make your change
git checkout -b my-change
./run.sh test   # the tests pass

# 3. Push the branch and open a pull request against kncept/quesadilla
git push origin my-change
```
